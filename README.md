# dotmac_governance

Normative governance for Dotmac engineering: policies, architecture decisions,
control interpretations, and evidence mappings.

**Status: empty. Nothing here is approved.**

This repository is created ahead of its contents deliberately. Governance needs
a single versioned owner *before* the first policy is written; drafting it
elsewhere first would create a temporary authority and guarantee migration drift.

The scaffold — authority model, agent constraints, ADR rules, evidence model —
arrives by pull request, because `main` changes by review.
